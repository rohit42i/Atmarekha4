# Atma Rekha — GitHub Mobile Ready

This version is intentionally **flat**: all application files are in the repository root.
This is designed for uploading from a phone without accidentally losing the `src/` folder.

## Cloudflare settings
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Root directory: `/`

## Important
Upload/replace **all files in this ZIP** in the GitHub repository root.
Do not create a `src` folder and do not put these files inside another folder.

Supabase is not connected yet. It can be added after the frontend is live.
